Hide Power By Odoo

Version: 1.0.0

Supported Odoo Versions: 17.0

Author: Legion Soft

Website: www.legionsoft.com

Description

This module removes "Powered by Odoo" branding from the browser tab, login page, email templates, and replaces the default favicon.

Features

  • Removes "Powered by Odoo" from the browser tab.
  • Hides branding from the login page.
  • Removes "Powered by Odoo" from email templates.
  • Replaces the default Odoo favicon with a custom one.

Installation

Simply install the module, and the changes will be applied automatically.
