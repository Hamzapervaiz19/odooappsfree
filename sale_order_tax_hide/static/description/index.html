Hide Taxes from Sale Order Lines

Simplify your Sale Order forms by removing unnecessary tax fields.

Overview

This Odoo module customizes the Sale Order form view by hiding the tax column from the Sale Order Lines. It's designed for businesses that don't need to manage taxes on a per-line basis and prefer a cleaner interface.

Features

  • Hides the tax_id field in the Sale Order Lines.
  • Improves the user interface by removing unnecessary details.
  • Seamlessly integrates with Odoo's default Sales module.

Technical Details

Compatible with: Odoo 18.0

Dependencies: Sale Module

Installation

  1. Copy the module folder sale_order_tax_hide to your Odoo addons directory.
  2. Restart the Odoo server:
    3. ./odoo-bin restart
  3. Update the app list in Odoo.
  4. Search for "Hide Taxes from Sale Order Lines" in the Apps menu and install it.

Usage

Once installed, the module will automatically hide the tax column from Sale Order Lines. No additional configuration is required.
